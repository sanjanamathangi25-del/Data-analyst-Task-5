# Data-analyst-Task-5
Task 5: Exploratory Data Analysis (EDA)

Project Overview

This project focuses on Exploratory Data Analysis (EDA) using the Titanic dataset. The main objective is to explore and analyze data using statistical methods and visualizations to identify patterns, trends, relationships, and anomalies.

Objective

To extract meaningful insights from the dataset through data exploration and visualization.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

Titanic Dataset

The dataset contains passenger information such as:

- Passenger ID
- Age
- Gender
- Ticket Fare
- Passenger Class
- Survival Status

Tasks Performed

1. Loaded and explored the Titanic dataset.
2. Checked dataset information using "info()".
3. Generated statistical summaries using "describe()".
4. Identified missing values and duplicates.
5. Analyzed relationships between numerical features.
6. Created visualizations using Matplotlib and Seaborn.
7. Used histograms, boxplots, scatterplots, heatmaps, and pairplots.
8. Identified patterns, trends, and important insights.

Visualizations

- Histograms – To understand data distribution.
- Boxplots – To identify outliers.
- Scatterplots – To identify relationships between variables.
- Heatmaps – To visualize correlations.
- Pairplots – To compare multiple numerical variables.

Key Findings

- Explored passenger age and fare distributions.
- Analyzed survival patterns based on gender and passenger class.
- Identified relationships between numerical variables.
- Observed missing values and possible outliers.

Deliverables

- Jupyter Notebook containing Python code and visualizations.
- PDF report explaining the findings and observations.

Conclusion

Exploratory Data Analysis helps understand datasets before applying machine learning algorithms. Through this task, I gained practical experience in data cleaning, statistical analysis, data visualization, and identifying meaningful patterns.
